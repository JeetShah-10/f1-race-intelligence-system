# Animation Directives

Describes motion behavior, timing, sequencing, and cinematic transitions.

---

## 1. Hero Reveal Sequence

Timeline:

0–1s fade from black + ambient hum
1–4s 3D car orbit + material highlight
4–6s circuit extrusion + sector color sweep
6–8s HUD telemetry build-in
8–9s framing panels slide
9–10s dashboard takeover


Tempo:
- cinematic
- premium
- confident pacing

---

## 2. Qualifying Simulation Animation

Events:
- sector flash (P/G/Y)
- lap time reveal slide
- tower position pulse for improvements
- predicted delta interpolation (future)
- tire compound indicator pop

Motion priority:
data clarity > cinematic motion

---

## 3. Race Simulation Animation

Key phases:

### (A) Start Procedure
● ● ● ● ● → lights out flash → motion blur kick
### (B) Live Updates
- tower reorder on overtakes
- delta bars slide
- pit markers fade-in/out
- SC introduces dim overlay layer
- DNF triggers removal + tower shrink

---

## 4. Results Animation

Transitions:
- results table fade
- stint chart wipe
- tire chart slide
- gap numbers animate numerically
- CTA buttons appear last (run again / save / compare)

---

## 5. User Interaction Motion

Interaction design:
- immediate response
- no sluggish animation
- modern spring physics minimal but present

Elastic easing:
cubic-bezier(0.17, 0.84, 0.44, 1)


---

## 6. Motion Constraints

Do not:
- over animate HUD
- introduce chaotic jitter
- block data readability

Animation must always:
- reinforce information hierarchy
- support simulation realism
